# Preserved Assets and Data Guide

This guide describes all files remaining in the project after the reset. These files contain the core identity, portfolio, and team data for building the new website.

## 📂 `src/data` (Core Information)

Contains the structured JavaScript objects that hold the website's content.

| File Name | Context / Purpose |
| :--- | :--- |
| `teamData.js` | **Team Information**: Contains names, roles, custom quotes, and image imports for all GenSync team members (Extract from original site). |
| `workData.js` | **Portfolio & Work**: Contains categories (Websites, Films, Branding, Social), project titles, descriptions, YouTube IDs for commercials, drive links, and project URLs. |
